Règle régionale du puzzle Yajilin

Yajilin régional (également connu sous le nom de "Yajilin (régions)") est une grille divisée en régions.L'objectif est de noircir certaines cellules et de dessiner une seule boucle non inférieure à travers toutes les cellules blanches.Un nombre dans une région indique le nombre de cellules noires dans cette région.Une région sans nombre peut contenir n'importe quelle quantité de cellules noires.Aucune cellule noire ne peut partager une frontière.La boucle peut visiter les cellules numérotées;Les cellules numérotées peuvent être noircies.
