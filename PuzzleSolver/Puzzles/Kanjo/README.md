Règles et astuces du Kanjo

Règles de puzzle Kanjo

Kanjo ("Kanjo-Sen Supesharu"; de Japonais, littéralement "Special Ring Line") est un puzzle logique.Une grille contient des cercles avec des nombres dans certaines cellules.L'objectif est de dessiner des boucles qui traversent correctement toutes les cellules.Une boucle peut se croiser ou d'autres boucles.Toutes les fragments de ligne donnés doivent être utilisés dans le cadre d'une boucle.Les cellules avec le même nombre appartiennent à la même boucle.Les cellules avec différents nombres appartiennent à différentes boucles.Une boucle doit aller au moins une cellule avec un nombre (il y a exactement autant de boucles qu'une grille contient des nombres différents).Une cellule avec un nombre ne doit pas contenir le point d'intersection où une boucle se croise ou une autre boucle.
