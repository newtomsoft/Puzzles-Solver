# Hashi

## Règles du jeu

Règles et astuces du Hashi (Ponts)

Hashiwokakero (du japonais "Hashi o kakero" ; littéralement "construire des ponts" ; également connu sous le nom de "Hashi", "Bridges", "Baguettes" ou "Ai-Ki-Ai") est un type de puzzle logique. Il se joue sur une grille rectangulaire sans taille standard, bien que la grille elle-même ne soit généralement pas dessinée. Certaines cellules commencent par des nombres (généralement encerclés) de 1 à 8 inclus ; ce sont les îles. Le reste des cellules est vide.

L'objectif est de relier toutes les îles en un seul groupe connecté en traçant une série de ponts entre les îles. Les ponts doivent suivre certains critères :

Règle Hashi

Ils doivent commencer et se terminer sur des îles distinctes, parcourant une ligne droite entre les deux.

Ils ne doivent traverser aucun autre pont ou île.

Ils ne peuvent fonctionner que de manière orthogonale.

Au maximum deux ponts relient une paire d'îles.

Le nombre de ponts connectés à chaque île doit correspondre au nombre sur cette île.
