# Sutoreto

## Règles du jeu

Règles et astuces du Sutoreto

Sutoreto ("Sutoretokurosu", "Straight Cross") est un puzzle logique créé par Naoki Inaba (Japon).Il se joue sur une grille rectangulaire ou carrée avec des cellules noires et blanches.Certaines cellules blanches contiennent des nombres.L'objectif est de placer un nombre dans chaque cellule blanche.Les nombres dans une bande horizontale ou verticale des cellules blanches consécutives doivent former une séquence de nombres sans lacunes, mais dans un ordre (par exemple: 2-4-1-3).
