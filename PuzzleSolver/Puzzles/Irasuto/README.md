# Irasuto

## Règles du jeu

Règles et astuces du Irasuto

Irasuto ("Illustration") est un puzzle logique créé par Naoki Inaba (Japon). Une grille rectangulaire ou carrée contient des cellules blanches et noires avec des chiffres. Le but est de noircir certaines cellules d'une grille selon les règles suivantes :

Un nombre dans une cellule blanche représente le nombre de cellules blanches vides visibles depuis cette cellule.

Un nombre dans une cellule noire représente le nombre de cellules noires vides visibles depuis cette cellule.
