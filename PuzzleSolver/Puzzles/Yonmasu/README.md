Règles du puzzle Yonmasu

Yonmasu ("Yonmasubunkatsu") est un puzzle logique inventé par Naoki Inaba (Japon).Une grille rectangulaire ou carrée contient des cercles dans certaines cellules.Le but est de diviser la grille en régions de quatre cellules exactement.Chaque région contient un cercle.
