# Arofuro

## Règles du jeu

Règles et astuces du Arofuro

Règles de puzzle Arofuro:

Arofuro ("Flèche Flow") est un puzzle logique.Une grille contient des nombres dans certaines cellules.L'objectif est de placer des flèches pointant dans quatre directions dans chaque cellule vide.

- Les mêmes flèches ne peuvent pas être placées dans des cellules adjacentes .

En commençant par n'importe quelle cellule avec une flèche, en suivant les flèches d'une cellule à l'autre, une cellule avec un nombre peut être atteinte.

Une cellule avec un nombre indique un nombre total de flèches qui mènent à cette cellule.
