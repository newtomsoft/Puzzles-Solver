# Context

## Règles du jeu

Règles et astuces du Contexte

Règles de puzzle de contexte:

Connectivité : Toutes les cellules blanches (cellules non remplies) doivent être connectées les unes aux autres horizontalement ou verticalement.

Placement des cellules noires:

- Une cellule contenant un nombre peut être remplie de noir.

- Aucune cellule noire ne peut être placée directement l'un à côté de l'autre horizontalement ou verticalement.

Signification du nombre:

- Un nombre dans une cellule blanc indique le nombre de cellules noires qui y sont directement adjacentes (horizontalement ou verticalement).

- Un nombre dans une cellule noire indique le nombre de cellules noires qui y sont adjacentes en diagonale.
