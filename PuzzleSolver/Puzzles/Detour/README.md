Letour est un puzzle logique.Il contient une grille rectangulaire ou carrée divisée en régions.L'objectif est de dessiner une seule boucle continue non d'intection qui visite chaque cellule exactement.Chaque nombre dans une région indique le nombre de fois où la boucle tourne dans la région.
