Règles et astuces du Kuroshuto

Règles de puzzle de Kuroshuto:

Remplissez des cellules vides avec du noir pour compléter le puzzle.

- Les nombres dans la grille indiquent le nombre de cellules noires exactement à cette distance.Les distances sont mesurées orthogonalement (horizontalement ou verticalement).

- Aucune cellule noire ne peut être placée à côté de l'autre horizontalement ou verticalement.

- Toutes les cellules blanches doivent être connectées.
