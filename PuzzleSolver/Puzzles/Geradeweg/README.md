# Geradeweg

## Règles du jeu

Règles et astuces du Geradeweg

Règles de puzzle Geradeweg (boucle droite)

Geradeweg ("Loop Straight") est un puzzle logique.Une grille contient des cercles avec des nombres dans certaines cellules.La tâche consiste à dessiner une seule boucle non intexée fermée qui passe par tous les cercles.Le nombre indique la longueur du segment droit passé à travers le cercle.Si la boucle transforme une cellule numérique, les deux segments droits doivent avoir la même longueur que le nombre l'indique.
