Règle du puzzle USOTATAMI

La grille Usotatami contient des nombres dans certaines cellules.L'objectif est de diviser la grille en régions rectangulaires de telle sorte que chaque région contient exactement un nombre.Chaque région doit être exactement une cellule de large;La longueur de l'autre côté n'est pas égale au nombre dans cette région.Un point de grille ne doit pas être partagé par les coins de quatre régions.
