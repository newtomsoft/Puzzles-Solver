# SeeThrough

## Règles du jeu

Règles et astuces du Seethrough

Voir à travers les règles du puzzle

Seethrough ("Doors", "Open Office") est un puzzle logique, où chaque cellule désigne une "salle".L'objectif est de fermer certaines «portes» entre les chambres.Les portes ouvertes permettent de regarder d'autres pièces.Le nombre dans la cellule indique le nombre total de pièces visibles dans la direction horizontale et verticale de cette pièce (la pièce elle-même exclue).Il ne peut y avoir de pièces isolées;Cela signifie que vous devriez pouvoir atteindre toutes les pièces en se déplaçant horizontalement et verticalement.
