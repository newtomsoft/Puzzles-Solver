# Hiroimono

## Règles du jeu

Règles et astuces du Hiroimono (Goishi Hiroi)

Hiroimono (également connu sous le nom de Goishi Hiroi) est un casse-tête logique dans lequel le résolveur doit collecter toutes les pierres d'une grille en se déplaçant le long des lignes.

1. Démarrer : Choisissez n'importe quelle pierre pour commencer.

2. Mouvement : Déplacez-vous le long des lignes de la grille d'une intersection à l'autre.

3. Collecter des pierres : Lorsque vous atteignez une pierre, vous devez la collecter (la numéroter dans l'ordre).

4. Changements de direction : Vous ne pouvez changer de direction que lorsque vous récupérez une pierre.

5. Pas d'inversion : Vous ne pouvez pas immédiatement inverser votre direction (c'est-à-dire tourner à 180 °).

### Techniques de résolution de puzzles Hiroimono

- Analyse de début/fin : recherchez les chemins sans issue ou les pierres qui doivent être collectées dans un ordre spécifique pour éviter de vous piéger.

- Connectivité : assurez-vous que toutes les pierres restent connectées via les chemins disponibles ;isoler une pierre signifie un échec.

- Déplacements forcés : Si une pierre n'a qu'un seul chemin adjacent accessible, elle dicte souvent la direction.

- Pairing Stones : Regroupez les pierres en paires ou en séquences qui doivent être collectées en un seul passage sans tours.

- Éviter les boucles : Faites attention aux chemins circulaires qui peuvent conduire à des pierres inaccessibles en cas d'entrée prématurée.
