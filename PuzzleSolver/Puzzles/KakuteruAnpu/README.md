# KakuteruAnpu

## Règles du jeu

Règles et astuces du Lampe Cocktail

Lampe à cocktail (Kakuteru ANPU) est un puzzle logique joué sur une grille divisée en régions irrégulières.L'objectif est d'ombrer certaines cellules noires tout en adhérant à ces règles:

● Les cellules noires de chaque région doivent former un seul groupe connecté (orthogonalement).

● Une cellule numérotée spécifie le nombre exact de cellules noires dans sa région.

● Les régions non numérotées peuvent avoir un certain nombre de cellules noires (y compris zéro).

● Les cellules adjacentes orthogonalement dans différentes régions ne peuvent pas être toutes les deux noires.

● Tous les groupes séparés à cellules noires doivent se connecter en diagonale (coin à cornère).

● Aucun carré 2 × 2 dans la grille ne peut être entièrement noir.
