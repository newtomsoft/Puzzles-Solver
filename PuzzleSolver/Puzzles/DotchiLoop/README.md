Règles de puzzle de boucle Dotchi

Dotchi-boucle est un puzzle logique publié par Nikoli.Une grille est divisée en régions.Une grille contient des cercles blancs et noirs dans certaines cellules.L'objectif est de dessiner une seule boucle non inférieure.La boucle doit visiter toutes les cellules avec des cercles blancs;La boucle ne peut pas traverser un cercle noir. La ligne se déplace directement à travers tous les cercles blancs, ou fait un virage de 90 degrés dans tous les cercles blancs d'une région.
