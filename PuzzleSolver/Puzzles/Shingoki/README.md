Feux de circulation (Shingoki) Règle de puzzle

Shingoki (des japonais, littéralement des "feux de circulation") est une grille avec des cercles dans certaines cellules.L'objectif est de dessiner une seule boucle continue continue qui passe à travers tous les cercles.Les cercles rouges doivent être allumés, les cercles verts doivent être voyagés directement.Dans une cellule avec un cercle jaune, la boucle peut tourner ou non.Si un cercle contient un nombre, ce nombre indique la longueur totale des lignes droites sortant du cercle.
