# YinYang

## Règles du jeu

Règles et astuces du Yin-Yang

Règles de puzzle yin-yang:

Le yin-yang se compose d'une grille avec des cercles blancs et noirs dans certaines cellules.L'objectif est de placer un cercle noir ou blanc dans chaque cellule vide afin que tous les cercles de même couleur soient connectés les uns aux autres, verticalement ou horizontalement.De plus, aucun groupe de cellules 2 x 2 ne peut contenir des cercles de la même couleur.
