# Hitori

## Règles du jeu

Règles et astuces du Hitori

Règle Hitori

Éliminez les nombres jusqu'à ce qu'il n'y ait plus de doublons dans aucune ligne ou colonne.

Éliminez les nombres en les marquant en noir.

Les carrés noirs ne peuvent pas se toucher horizontalement ou verticalement (la diagonale est acceptable).

N'importe quel carré blanc peut être atteint depuis n'importe quel autre (c'est-à-dire qu'ils sont connectés).
