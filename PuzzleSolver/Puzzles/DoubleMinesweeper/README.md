# DoubleMinesweeper

## Règles du jeu

Règles et astuces du Double Minesweeper

Règles de puzzle à double rames:

Le dragueur de mines est bien connu par le jeu dans Microsoft Windows.La tâche consiste à placer les mines dans des cellules vides dans la grille.Les chiffres de la grille représentent le nombre de mines dans les cellules voisines, y compris celles diagonales.

Double Minesweeper : Placez les mines dans chaque cellule vide de la grille, au plus deux mines par cellule.
