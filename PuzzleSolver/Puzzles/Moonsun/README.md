Règles de puzzle Moonsun

Moonsun ("Lune ou Soleil") est une grille est divisée en régions.Une grille contient des cercles en noir et blanc dans certaines cellules.L'objectif est de dessiner une seule boucle non inférieure.La boucle doit franchir les bordures de chaque région exactement deux fois.Dans une région, la boucle doit visiter toutes les cellules avec des cercles noirs ou toutes les cellules avec des cercles blancs.Les régions avec des cercles noirs visités doivent alterner avec les régions, où les cercles blancs ont été visités.
