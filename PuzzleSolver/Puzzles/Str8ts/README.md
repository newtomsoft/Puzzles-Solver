# Str8ts

## Règles du jeu

Règles et astuces du Str8ts

Str8ts (également connu sous le nom de "Straights") est un casse-tête logique inventé par Jeff Widderich (Canada). Il s'agit d'une grille partiellement divisée en compartiments par des cellules noires. Chaque compartiment, verticalement ou horizontalement, doit contenir une suite - un ensemble de nombres consécutifs, mais dans n'importe quel ordre (par exemple : 2-1-3-4). Le but est de remplir toutes les cellules blanches avec les nombres de 1 à N (où N est la taille de la grille). Aucun nombre ne peut se répéter dans une ligne ou une colonne. Les indices dans les cellules noires suppriment ce numéro en tant qu'option dans cette ligne et cette colonne, et ne font partie d'aucune ligne droite.
