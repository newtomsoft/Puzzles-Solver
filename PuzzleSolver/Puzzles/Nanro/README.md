# Nanro

## Règles du jeu

Règles et astuces du Nanro

Règles de puzzle nanro:

Nanro est un puzzle logique.La tâche se compose d'une grille divisée en régions.L'objectif est de remplir certaines cellules avec des nombres.

Tous les chiffres dans une région doivent être les mêmes.

Le nombre donné dans une région indique le nombre de cellules de cette région contiennent un nombre (toutes les régions doivent avoir au moins un nombre).

Lorsque deux nombres sont adjacents orthogonalement à travers une limite de région, les nombres doivent être différents.

Les cellules numérotées ne doivent pas couvrir une zone de taille 2 x 2 ou plus.

Toutes les cellules avec des nombres doivent être interconnectées.
