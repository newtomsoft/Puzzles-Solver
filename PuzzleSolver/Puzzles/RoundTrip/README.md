Règles de puzzle aller-retour

L'entretien aller-retour est une sorte de puzzles logiques.L'objectif est de dessiner une seule boucle dans une grille.Une boucle peut se croiser orthogonalement, mais sinon, ne se touche pas ou ne se rétracte pas.Les nombres le long du bord du puzzle indiquent le nombre de cellules visitées par la section la plus proche de la boucle en ligne ou colonne correspondante.
