# Buraitoraito

## Règles du jeu

Règles et astuces du Buraitoraito

Règles de puzzle Buraitaito:

Buraitaitait ("Lumière vive") est joué sur une grille rectangulaire ou carrée.Il contient des cellules noires avec des nombres.Le nombre dans la cellule représente le nombre d'étoiles que l'on peut voir à partir de cette cellule.Une étoile est visible à partir de la cellule noire, si elle se trouve dans la même ligne ou la même colonne que cette cellule, mais pas derrière d'autres cellules noires.
