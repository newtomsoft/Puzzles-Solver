# Chocona

## Règles du jeu

Règles et astuces du Chocona

Règles de puzzle chocoon:

Chocona ("chocolat") se compose d'une grille rectangulaire ou carrée divisée en régions.L'objectif est de noircir certaines cellules d'une grille selon les règles suivantes:

1. Régions numérotées: Les cellules avec des nombres spécifient le nombre exact de cellules qui doivent être noircies dans cette région.

2. Régions non nugnées: Les régions sans nombres permettent à un nombre de cellules de noirci, y compris zéro.

3. Formation rectangulaire: Les cellules noircies doivent toujours former des formes rectangulaires, quelles que soient les limites de la région.

4. Non-adjaction: Les rectangles noirs ne peuvent pas être directement adjacents les uns aux autres horizontalement ou verticalement.
