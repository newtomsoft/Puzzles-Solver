## Règles du jeu

Règles et astuces du Yajikabe

Règles de puzzle Yajikabe:

Yajikabe il a combiné yajilin et Nurikabe puzzles.L'objectif est de noircir certaines cellules d'une grille selon les règles suivantes:

- Les cellules avec des nombres sont toujours blanches.

- La zone cellulaire non 2 x 2 dans la grille peut contenir toutes les cellules noires.

- Toutes les cellules noires forment une région contiguë.

- Une cellule contenant un nombre et une flèche représente le nombre de cellules noires dans la ligne ou la colonne pointée par la flèche.
