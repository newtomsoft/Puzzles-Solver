Meadows Puzzle Rule

Meadows est un puzzle logique.Il se joue sur une grille rectangulaire ou carrée.Certaines cellules contiennent des cercles.L'objectif est de diviser la grille en blocs carrés de telle sorte que chaque bloc contient exactement un cercle.
