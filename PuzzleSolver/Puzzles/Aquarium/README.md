# Aquarium

## Règles du jeu

Règles et astuces du Aquarium

Règles de puzzle d'aquarium:

- Les nombres à l'extérieur de la grille indiquent le nombre de cellules remplies dans chaque ligne et colonne.

- Remplissez certaines cellules avec de l'eau pour correspondre aux nombres donnés.

- Les zones connectées des cellules remplies doivent avoir le même niveau d'eau.
