Règles Tatamibari

Tatamibari est un puzzle logique où l'objectif est de diviser une grille rectangulaire ou carrée dans les régions rectangulaires.

Symboles : La grille contient trois types de symboles:

croix : La région contenant une croix doit être un carré.

Bar horizontale : La région contenant une barre horizontale doit être plus large qu'elle n'est grande.

Barre verticale : La région contenant une barre verticale doit être plus grande qu'elle n'est large.

Restrictions de région:

- Chaque région doit contenir exactement un symbole.

- Aucun point de grille ne peut être partagé par les coins de quatre différentes régions.
