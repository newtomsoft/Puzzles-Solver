## Règles du jeu

Règles et astuces du Heyawake

Règles de puzzle Heyawake ::

Chambres numérotées : Certaines chambres contiennent un seul numéro.Ce nombre indique la quantité exacte de cellules dans cette pièce qui doit être peinte en noir.

Restrictions de cellules noires :

- Les cellules noires ne peuvent pas être placées adjacentes les unes aux autres horizontalement ou verticalement.

- Toutes les cellules blanches doivent être connectées.

- Une ligne de cellules blanches connectées ne peut pas connecter plus de deux pièces.
