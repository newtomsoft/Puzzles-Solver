Règles et astuces du Puzzle Corral

Règles de puzzle Corral

Corral (également connu sous le nom de "sac", "Cave") est un puzzle logique inventé par Nikoli.L'objectif est de dessiner une seule boucle fermée le long des lignes de grille qui ne se croisent pas.La boucle contourne tous les chiffres.Les nombres dans la grille indiquent le nombre de cellules à l'intérieur de la boucle que l'on peut voir horizontalement et verticalement à partir de cette cellule, y compris la cellule elle-même.Les points d'interrogation peuvent être utilisés au lieu des numéros d'indice.Chaque point d'interrogation peut représenter tout entier non nul.
