# Island

## Règles du jeu

Règles et astuces du Puzzle Île

Island (également connue sous le nom de « Tents Island », « Airando ») est un puzzle logique inventé par Naoki Inaba (Japon).Il s'agit d'une grille, avec des nombres dans certaines cellules.Le but est de noircir certaines cellules d'une grille selon les règles suivantes :

- Les globules blancs forment un seul îlot.Chaque cellule numérotée doit faire partie de cette île.

- Les nombres indiquent combien de cellules blanches non numérotées peuvent être atteintes à partir de cette cellule en se déplaçant horizontalement ou verticalement.Les cellules numérotées bloquent l'accès.

### Puzzle de l'île (île aux tentes) - Conseils de résolution

1. Commencez par les plus grands nombres

Des nombres élevés (par exemple 4, 5) forcent souvent de longs trajets de globules blancs dans les directions qu’ils peuvent « voir ».Marquez le maximum de cellules blanches possibles qui en rayonnent, en respectant les bords de la grille et les bloqueurs de cellules numérotées.

2. Utilisez la logique de « blocage »

Les cellules numérotées bloquent la vision, donc si une cellule numérotée est adjacente à une autre, aucune ne peut compter l’autre.Cela oblige souvent les cellules blanches à s’éloigner des cellules numérotées.

3. Gardez l'île connectée

Les globules blancs finaux doivent former un groupe connecté orthogonalement contigu.Lorsque vous marquez des cellules blanches, assurez-vous qu’elles ne créent pas de groupes blancs isolés qui ne peuvent pas rejoindre l’île principale.

4. Stratégie Edge-Numéro

Une cellule numérotée sur le bord ou le coin de la grille a des directions limitées pour se développer.Son décompte doit être satisfait uniquement dans les directions disponibles.

5. Évitez les impasses prématurément

Ne noircissez pas une cellule si cela empêcherait une cellule numérotée d’atteindre le nombre requis ou déconnecterait l’îlot.

6. Comptes de recoupement

Pour une cellule numérotée, comptez le nombre de cellules non numérotées accessibles dans ses quatre directions (arrêtées par des cellules numérotées ou des cellules noires).Si le maximum possible correspond à l’indice, ceux-ci doivent être blancs.S’il n’y a pas suffisamment de cellules, les cellules noires antérieures pourraient être erronées.

7. Test de contradiction

En cas de doute, noircissez provisoirement une cellule et vérifiez si le décompte d’une cellule numérotée devient impossible ou si la connectivité est interrompue.Si tel est le cas, cette cellule doit être blanche.

8. Propagation via la connectivité

Souvent, un pont de cellules blanches est nécessaire pour relier deux parties de l’île.Recherchez les cellules numérotées qui sont éloignées les unes des autres : leurs zones blanches devront peut-être se connecter via des chemins partagés.

Dernier indice : Le puzzle combine le « compte des cellules visibles » (comme une logique de phare simplifiée) avec des contraintes de connectivité.La patience avec la déduction progressive est payante.
