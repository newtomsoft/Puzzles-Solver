# Nuribou

## Règles du jeu

Règles et astuces du Nuribou

Règles de puzzle de Nuribou:

Nuribou est un puzzle logique.Une grille rectangulaire ou carrée contient des nombres dans certaines cellules.La tâche consiste à noircir certaines cellules vides selon les règles:

- Les cellules noires divisent la grille dans les zones des cellules blanches.Chaque zone contient une cellule avec un nombre.

- Chaque zone doit avoir le même nombre de cellules blanches que le nombre qu'il contient (y compris la cellule numérotée).

- Les cellules noires forment des rayures horizontales ou verticales, qui ne doivent pas être adjacentes à l'orthogon.Chaque bande doit être exactement une cellule de large.

- Si deux bandes sont connectées en diagonale, la longueur des rayures doit être différente.
