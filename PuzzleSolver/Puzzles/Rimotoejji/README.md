# Rimotoejji

## Règles du jeu

Règles et astuces du Rimotoejji

Règles de puzzle de bord distant

Remote Edge (Rimotoejji) est un puzzle logique créé par Naoki Inaba (Japon).L'objectif est de connecter tous les points par une seule boucle continue non d'intection.Toutes les flèches et les croix sont censés être contenus dans la boucle.Une flèche pointe dans le sens de la plus longue séquence droite de cellules visibles de cette cellule.Une croix est placée au centre de plus d'une plus longue séquence de cellules droites dans la boucle.
