# CornerLoop

## Règles du jeu

Règles et astuces du Konarupu

Règles de puzzle de boucle d'angle

Corner Loop ("Konarupu") est un puzzle logique inventé par Naoki Inaba (Japon).L'objectif est de créer une boucle continue non d'intection, tirée d'un point à un point adjacent horizontalement ou verticalement.Un nombre dans une cellule indique combien de fois la boucle tourne de 90 degrés dans des points entourant cette cellule.

Puzzle de boucle d'angle

Solution de puzzle de boucle d'angle

Slitherlink: le nombre à l'intérieur d'un carré représente le nombre de ses quatre côtés segments dans la boucle.

Boucle d'angle ("Konarupu"): Un nombre dans une cellule indique combien de fois la boucle tourne de 90 degrés dans des points entourant cette cellule.
