# Fillomino

## Règles du jeu

Règles et astuces du Fillomino

Règles de puzzle Fillomino

La grille : vous jouez sur une grille rectangulaire de carrés.

Le but : Divisez la grille en blocs de cellules connectées.

Clues : Certaines cellules contiennent des nombres. Chaque numéro vous indique combien de cellules doivent être dans le bloc à laquelle il appartient.

Les règles:

Les blocs avec le même nombre ne peuvent pas se toucher, horizontalement ou verticalement.

Les blocs peuvent avoir n'importe quelle forme, mais ils doivent être connectés.

Les cellules sans nombres pourraient avoir besoin de former des blocs pour compléter le puzzle.

En termes plus simples:

Imaginez la grille comme une carte.Vous devez dessiner des "pays" sur la carte.Chaque pays a une taille de population (le nombre dans la cellule).Les pays ayant la même population ne peuvent pas partager une frontière.Votre travail consiste à dessiner les frontières de tous les pays sur la carte.

Solution de puzzle Fillomino

Variations de remplios puzzles:

- Trinudo （Un mini puzzle Fillomino!Utilisez seulement 1, 2 ou 3 pour remplir la grille, en suivant les règles de Fillomino classiques.）

- tous les Evens Fillomino La taille de chaque région doit être un nombre pair.

- toutes les cotes Fillomino La taille de chaque région doit être un nombre impair.

- Aucune ligne /colonne répète Fillomino dans chaque ligne et chaque colonne, toutes les cellules avec le même nombre doivent appartenir à la même région.

- Fillomino consécutif Toute région de taille n doit être orthogonalement adjacente à au moins une autre région de taille N-1 ou N + 1.

- Fillomino non consécutif Deux régions adjacentes doivent différer en taille d'au moins deux.

- Non 2 x 2 carrés Fillomino NO 2 x 2 La zone cellulaire dans la grille peut contenir les mêmes nombres.

- Seuls les rectangles Fillomino Toutes les régions doivent être rectangulaires.

- Pas de rectangles Fillomino Les régions rectangulaires ne sont pas autorisées.
