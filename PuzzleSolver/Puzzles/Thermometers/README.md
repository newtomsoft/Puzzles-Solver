Puzzle des thermomètres

Les thermomètressont un type fascinant de puzzle logique joué sur une grille.La grille est remplie de formes de thermomètre, chacune composée d'une "base" circulaire et d'une "tige" linéaire.

L'objectif est de déterminer quels segments de chaque thermomètre sont remplis.Voici comment cela fonctionne:

Règles de remplissage: Les thermomètres sont toujours remplis de leur base (la partie circulaire) le long de la tige.Ceci est crucial: même si un thermomètre est dessiné horizontalement ou en diagonale, le "remplissage" commence toujours à la base et s'étend séquentiellement vers la pointe.

États:Chaque segment de thermomètre peut être dans l'un des trois états:

1.Non rempli:Le segment est vide.

2.Partiellement rempli:Certains segments sont remplis, à partir de la base.Cela implique que tous les segments entre la base et le dernier segment rempli sont également remplis.

3.Complètement rempli:Tous les segments du thermomètre sont remplis.

Clues: Les numéros sont fournis le long de l'extérieur de la grille, généralement pour chaque ligne et colonne.Ces nombres indiquent le nombre total de carrés remplis dans cette ligne ou cette colonne spécifique.

Pour résoudre le puzzle, vous utilisez ces indices de somme de lignes et de colonnes, combinés avec la règle de remplissage "de base" pour chaque thermomètre, pour déduire logiquement les carrés doivent être remplis et lesquels doivent rester vides.
