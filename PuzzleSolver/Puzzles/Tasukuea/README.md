Règles et astuces du Tasukuea

Règles de puzzle logique Tasukuea:

Tasukuea (des japonais, littéralement «trouver des carrés») est un type de puzzles logiques.Il est joué sur une grille rectangulaire ou carrée avec des nombres ou des signes de question dans certaines cellules.L'objectif est de noircir certaines cellules d'une grille selon les règles suivantes:

Les cellules avec des nombres ou des signes de question ne peuvent pas être noircis.

Les cellules noires forment des zones carrées qui ne doivent pas être adjacentes à l'orthogon.

Un nombre dans un cercle indique le nombre total de cellules noires dans les zones voisines orthogonalement la cellule numérotée.

Une cellule avec un signe de question doit avoir au moins une cellule noire adjacente.

Toutes les cellules blanches doivent être connectées horizontalement ou verticalement.
