Règles et astuces du Kurotto

Règles de puzzle de Kurotto:

Kurotto (des japonais, littéralement "unités noires") est un puzzle logique.La tâche se compose d'une grille, avec des cercles dans certaines cellules;Un cercle peut avoir un nombre à l'intérieur ou non.La tâche consiste à noircir certaines cellules d'une grille selon les règles suivantes:

- Les cellules avec des cercles ne peuvent pas être noircies.

- Les cellules noires forment des zones contiguës orthogonalement.

- Un nombre dans un cercle indique le nombre total de cellules noires dans les zones qui voilà orthogonalement la cellule encerclée.

- Les cellules avec des cercles vides peuvent avoir un certain nombre de cellules noires autour d'eux.
