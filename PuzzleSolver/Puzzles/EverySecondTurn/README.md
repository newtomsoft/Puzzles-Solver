# EverySecondTurn

## Règles du jeu

Règles et astuces du Chaque Second Virage

Tous les règles de puzzle à chaque deuxième tour

Chaque deuxième virage (également connu sous le nom de «coins alternatifs», «chaque deuxième point de rupture») est une grille avec des cercles dans certaines cellules.L'objectif est de dessiner une seule boucle continue continue qui ne visite chaque cellule.Il fait tourner à 90 degrés à chaque cellule avec un cercle.Il y a exactement un tour entre deux cercles consécutifs que la boucle visite.
