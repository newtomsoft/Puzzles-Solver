Règles et astuces du Usowan

Règles du puzzle usowan:

Une grille est divisée en régions rectangulaires et carrées.Certaines cellules contiennent des nombres.Remplissez certaines cellules de noir selon ces règles:

- Les cellules numérotées restent blanches.

- Un nombre indique le nombre de cellules noires autour de lui, mais un nombre par région est faux.

- Les cellules noires ne peuvent pas toucher horizontalement ou verticalement.

- Toutes les cellules blanches doivent être connectées.
