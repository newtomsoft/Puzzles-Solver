# Mobiriti

## Règles du jeu

Règles et astuces du Mobiriti

Règles de puzzle Mobiriti:

Mobiriti ("Mobility") est un puzzle logique créé par Naoki Inaba (Japon).Une grille contient des cercles avec des nombres dans certaines cellules.L'objectif est de noircir certaines cellules d'une grille.Les cellules avec des cercles ne peuvent pas être noircies.Un nombre dans un cercle indique combien de cellules blanches vides peuvent être atteintes de cette cellule en se déplaçant horizontalement ou verticalement.
