How to play Knossos

Knossos Puzzle Rule

Grid: Played on a rectangular grid.
Numbers: Some cells contain numbers.
Regions: Divide the grid into regions (rooms).
Rule: Each region must contain exactly one number.
Number Meaning: The number within a region represents the total length of the region's borders.
