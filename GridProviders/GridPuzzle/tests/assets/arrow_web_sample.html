How to play Arrow Web

Arrow Web is a logic puzzle. A grid is filled by arrows. The goal is to shade some of the arrows so that each arrow in the grid points to exactly one shaded arrow.

Read more: Arrow Web rules & tips

Shade some arrows black such that each arrow (whether black or white) points to exactly one black arrow.
